# Edition comparison

Snapshot of the repository at v2.15.9. This describes implemented scope, not a parity promise. The Rust desktop app is the primary target for the UI work; the PowerShell and Linux editions remain independent products.

## Rust desktop baseline and gaps

The Rust app has thirteen Optimaxer pages: Overview, Performance, Diagnostics, System Snapshot, Processes, Gaming, Activity, Tweaks, Services, Startup, Cleaner, Network and Tools. Overview samples CPU, physical memory, system-drive capacity, uptime and process count. Performance charts CPU, memory, aggregate physical-disk throughput, receive/send byte rates from active non-loopback adapters, busiest GPU-engine utilization and dedicated GPU memory once per second while Overview or Performance is visible. Disk readings use the Windows PhysicalDisk `Disk Bytes/sec` counter; virtual network adapters may be included, so network readings are adapter traffic rather than internet throughput. Unsupported counters are shown as unavailable. Diagnostics runs only the read-only SFC `/verifyonly` and DISM `/Online /Cleanup-Image /ScanHealth` checks, displaying exit codes and bounded captured output; repair actions remain in Tools. System Snapshot stores the current OS, CPU, GPU names, logical thread count, memory, system-volume capacity and uptime locally, retaining the 30 newest records; it compares the two newest captures for changes to inventory and total capacity, excluding changing used-space and uptime readings. It is an inventory and cannot restore Windows. The read-only Processes page samples each accessible process's CPU time, working set and image path every three seconds while open; protected or inaccessible process fields remain unavailable. CPU is normalized to total logical processor capacity and is a short-interval estimate. The Gaming page displays current state for four existing reversible gaming tweaks and offers hardware-filtered apply/undo through the existing confirmation flow. It also supports manually added executable profiles for Windows per-game GPU preference, with exact saved-original restoration and external-change conflict protection. Preference-only JSON presets can be imported/exported; executable paths and saved Windows values are excluded. Game library scans, standalone Game Mode/DVR status and gaming history are not implemented. Publisher details, process termination and process inspection details are not implemented. The latest 100 confirmed tweak apply/undo batches are saved locally. Activity merges these records with up to 100 bounded system-action records for confirmed service, startup, cleaner, DNS, network reset, tool, installer launch, registry export and undo-all jobs in one timestamp-sorted, searchable timeline. Operation records label worker-reported warnings and errors and retain bounded output; a finished worker does not verify final system state or provide undo data. The download manager can cancel downloads; running Windows system operations cannot currently be cancelled. Read-only scans and benchmarks are excluded. Separate `operations.json` preserves these records in the app data directory.

Overview recommendations link to eligible inactive Smart Optimize settings and offer a cleanup scan when measured system-drive use reaches 90%. They never apply tweaks or delete files.

Settings expose system/light/dark mode, Windows/Classic/Material control styling, 16 named color palettes, custom accent and editable light/dark surfaces, reduced motion, comfortable/compact density, 90–125% interface scale, optional 0–16 px corner radius, update checks, download location and restore-point preference. Palette choice remains separate from control shape; custom text and accent are adjusted for contrast. Version 4 appearance presets include custom surfaces; versions 1 through 3 import with defaults for fields they predate. The Optimaxer rail can collapse to icons and remembers that choice; Store navigation stays expanded. The Tweaks page supports named selection profiles, portable JSON import/export and a read-only differences view for two saved profiles. Tweak batches that change settings requiring a Windows restart set a persisted reminder, cleared after system uptime resets. The notification center aggregates restart, update, operation and download status, with relevant actions and bounded dismissal storage. Performance does not include GPU temperature or dedicated-memory capacity readings. Gaming executable profiles remain limited to manual executable profiles; library scanning and separate gaming history are not implemented. Existing exact-undo records, service backups and confirmation previews remain the source of truth for their respective operations.

The Tweaks catalog supports applied-state, recommendation, favorite and hardware-compatibility filters, plus name, risk and status sorting within categories. Favorite IDs persist with local settings. These controls only change catalog visibility and ordering. A pinned action bar stays visible while the catalog scrolls and offers preview, undo, save-profile and clear-selection actions with recommended and review counts. The Gaming page and this Diagnostics page are both available in navigation and the searchable command palette. `Ctrl+K` and the visible Commands button also expose Store search, Downloads and Settings. The palette routes only to existing operations and does not trigger system changes.

## Next implementation constraints

- Keep controls attached only to implemented operations. New destinations require a complete read/change/restore path before they appear in navigation.
- Add measurements only when a real platform probe, error state and units are defined.
- Extend theme choices through validated token sets and contrast checks; keep shape style and color palette separate.
- Keep PowerShell-only Windows operations out of Linux and Rust until each port has a tested native implementation.
- Update this comparison when source behavior changes; use the edition READMEs for operational instructions and [verification.md](verification.md) for test evidence and remaining machine-level checks.
