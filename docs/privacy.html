Privacy Policy

Last updated 9 October 2026

Optimaxer does not collect, send or sell personal data. It has no accounts, analytics or telemetry, and the author receives nothing from your computer.

Files kept on your computer

  • Windows: a log, settings, tweak undo state, service backups and an icon cache in %ProgramData%\Optimaxer; the program in %LOCALAPPDATA%\Optimaxer.
  • Linux: undo state and config backups in /var/lib/optimaxer.

They stay there. Delete the folders to remove them.

Network requests the software makes

Only the following, and only to do what you asked. The author runs none of these servers and none of the requests carry an ID that identifies you.

  • GitHub (api.github.com, github.com): update check, release download, installer. GitHub sees your IP address and user agent, covered by its privacy statement.
  • jsDelivr (cdn.jsdelivr.net): app icons for the Install tab.
  • Google favicon service: a fallback icon for apps with no icon in the packs. The request names the app's website, not you.
  • raw.githubusercontent.com (WindowsSpyBlocker list): only when you apply the optional hosts-file telemetry block.
  • Package sources you choose to use: WinGet and the Microsoft Store on Windows; pacman mirrors, the AUR and Flathub on Linux. Their own policies apply.
  • A DNS provider, if you switch DNS in the Network tab. That provider then sees your DNS queries.

Privacy tweaks

Some tweaks lower the data Windows or other software sends to its vendor. That changes what those vendors receive. It does not send anything to the Optimaxer author.

This website

Static pages on GitHub Pages. No cookies, analytics or third-party scripts. GitHub may log visits under its own policy.

Children

The software collects no data from anyone, including children.
