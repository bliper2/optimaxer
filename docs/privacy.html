Privacy Policy

Last updated 4 November 2026

Optimaxer collects no personal data. It has no accounts, analytics or telemetry, and the author receives nothing from your computer. This page lists what the software stores on your PC and every network request it can make.

Files kept on your computer

  • Rust desktop app: settings, the catalog cache, update staging and download history in %LOCALAPPDATA%\OrionStore. Optimaxer's own records sit in %LOCALAPPDATA%\OrionStore\optimaxer: tweak undo records and backups, tweak and operation history, system snapshots, saved profiles, game profiles, benchmark captures and the Black Box history. Downloads go to the folder you pick in Settings.
  • PowerShell edition: a log, settings, tweak undo state, service backups and an icon cache in %ProgramData%\Optimaxer. The program lives in %LOCALAPPDATA%\Optimaxer.
  • Linux edition: undo state and config backups in /var/lib/optimaxer.

These files stay on your PC. You can delete the folders at any time to remove them.

Black Box, Bottleneck Detective and Startup X-Ray

  • Black Box is off until you turn it on. While it is on, it saves processor, memory, disk, network and GPU readings every 5, 10 or 30 seconds, plus any bookmarks you write. It keeps the newest 8,640 readings in blackbox.json. It does not record process names, window titles, file names or the content of anything you do. Nothing leaves your PC unless you export a report or CSV and share it yourself. Turning it off stops recording, and "Delete history" removes the file.
  • Bottleneck Detective reads the same counters for 30 seconds, plus the names and processor use of running programs, and keeps the result in memory only. It sends nothing.
  • Startup X-Ray reads Windows' own boot performance log on your PC. The "System log" lookups in Black Box and Startup X-Ray read your Windows event log locally and list provider names and event IDs.

Network requests the software makes

Only the requests below, and only to do what you asked. The author runs none of these servers, and no request carries an ID that identifies you.

  • GitHub (api.github.com, github.com): update checks, release downloads, installers, the PresentMon download and publisher avatars used for app icons. GitHub sees your IP address and user agent under its privacy statement.
  • Catalog refresh in the Rust desktop app: GitHub, GitLab, Codeberg and jsDelivr mirrors of Orion-Data. Catalog images and screenshots load from their published URLs. App downloads contact the server named by the download link you pick.
  • Icon services: jsDelivr (cdn.jsdelivr.net) and Simple Icons (cdn.simpleicons.org) for app icons in the Install and WinGet catalogs. Google, Gstatic and DuckDuckGo favicon services provide fallback icons, and those requests name the app's website.
  • Intel PresentMon: when you first record a game benchmark, the app downloads PresentMon from its GitHub release and checks it against the published SHA-256.
  • Latency measurement: the Performance measurement in the Rust desktop app opens ten short TCP connections to 1.1.1.1 on port 53 (Cloudflare) and records how long they take. Cloudflare sees your IP address.
  • DNS benchmark: when you choose "Benchmark servers," the app sends five UDP A-record queries for example.com to the first IPv4 DNS server of each listed provider. Your configured DNS does not change. Those servers receive the test domain and your network address.
  • DNS provider you choose: if you switch DNS in the Network page, that provider sees your DNS queries from then on. If you pick a provider with DNS over HTTPS, Windows contacts it directly.
  • raw.githubusercontent.com (WindowsSpyBlocker list): only when you apply the optional hosts-file telemetry block.
  • Package sources you choose to use: WinGet and the Microsoft Store on Windows, and pacman mirrors, the AUR, dnf repositories and Flathub on Linux. WinGet opens in its own console and its own policies apply. Optimaxer does not accept package agreements for you.

Privacy tweaks

Some tweaks lower the data Windows or other software sends to its vendor. That changes what those vendors receive. It sends nothing to the Optimaxer author.

This website

These are static pages on GitHub Pages. They use no cookies, analytics or third-party scripts. GitHub may log visits under its own policy.

Your rights and choices

  • You can read, move or delete every file listed above.
  • Because the author holds no data about you, there is nothing to request, correct or erase on the author's side. For data held by GitHub, Cloudflare or another service named above, use that service's own privacy tools.
  • You can disable the in-app update check in Settings.

Children

The software collects no data from anyone, including children.

Changes

Changes appear on this page, and the history is in the repository. Questions go to the issue tracker.
