What the software does

Optimaxer changes system settings, services, scheduled tasks, startup entries, the hosts file, installed packages and files, and needs administrator (Windows) or root (Linux) rights to do it. You choose what is applied. Most changes record the original value so they can be undone. Some cannot be: deleted temp and cache files, cleared event logs and the emptied Recycle Bin. Removed apps and packages can be reinstalled but their local data may be gone.

Your responsibility

  • Back up important data and make a restore point or snapshot first. The Windows version offers to create a restore point.
  • Read each tweak's description. Those marked Moderate or Advanced can turn off features you use, such as Windows Update, indexing or the Microsoft Store.
  • Make sure your use is allowed by your employer, school or device administrator, and by the licenses of any software you change or install.
  • The Linux edition has been tested only on a simulated system. Use --dry-run first.
