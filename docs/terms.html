What the software does

Optimaxer changes system settings, services, scheduled tasks, startup entries, the hosts file, installed packages and files. It needs administrator rights on Windows or root on Linux to do so. You choose what runs. Most changes record the original value so you can undo them. Some cannot be undone: deleted temporary and cache files, cleared event logs and the emptied Recycle Bin. Removed apps and packages can be reinstalled, but their local data may be gone.

The desktop app can restart File Explorer after a tweak or Smart Optimize run. Open File Explorer windows close and reopen. You can turn this off in the confirmation window.

Your responsibility

  • Back up important data and make a restore point or snapshot before large changes. The Windows editions offer to create a restore point.
  • Read each tweak's description. Tweaks marked Moderate or Advanced can turn off features you use, such as Windows Update behavior, indexing, BitLocker device encryption or the Microsoft Store.
  • Make sure your use is allowed by your employer, school or device administrator, and by the licenses of any software you change or install.
  • The Linux edition has been tested on a simulated system. Run it with --dry-run first.

Diagnostics and benchmarks

Black Box, Bottleneck Detective, Startup X-Ray, the benchmark tools and the system snapshots report measurements and observations. They do not diagnose faults, and a finding marked as a hypothesis is a guess. Results vary between runs and between PCs. Do not rely on them for decisions about safety, warranty or data recovery.

Updates

The software can check GitHub for new releases. It downloads an update only when you press the update button, and it checks the file against the SHA-256 that GitHub publishes before it replaces anything. A release without a checksum is refused. Updates may change how the software behaves, and you can keep using an older release.
