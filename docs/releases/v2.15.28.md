# v2.15.28

Cleaner size scans can now be cancelled from the Operation Center. Cancellation is checked during wildcard expansion and directory traversal; partial sizes and scan-derived selections are discarded. The cancel token is limited to this read-only scan path. Cleanup, previews and other system-changing jobs remain non-cancellable.

Verification: Rust passes 299 tests with 7 ignored; Clippy, formatting and the optimized build pass. Windows PowerShell passes 60 tests and Linux passes 100. Unit tests cover immediate and mid-directory cancellation. On Windows, the real scan showed the in-progress control, but completed before a click could be delivered; successful UI-triggered cancellation remains unverified.
