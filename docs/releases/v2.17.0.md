# v2.17.0

Five glass themes, theme previews in Settings, multi-select app installs, and an automatic File Explorer restart after tweaks. The PowerShell and Linux editions are unchanged apart from the aligned version number.

## New in the desktop app
- **Glass style and five new themes**: Noir Glass, Cobalt, Onyx, Slate and Mica, modelled on modern dark dashboards. The Glass style has larger radii, a lit top edge on cards and a soft accent glow behind the content. "... glass theme" commands in the command palette set a palette and the style together.
- **Layouts that follow the theme**: Noir Glass, Cobalt and Mica show the Overview as a ring-gauge dashboard with quick-action tiles; Onyx and Slate show it as a compact list of measured rows. Other themes keep the standard cards. Readings Windows does not give are shown as unavailable, never as zero. The layout change covers the Overview page; other pages keep their layout and take the theme's colours and shapes.
- **Theme previews**: Settings shows a miniature of the app in every palette, with its name, instead of a text list.
- **Install several apps at once**: tick any number of apps in the WinGet page and choose Install selected or Upgrade selected. You review every exact command first, WinGet opens one visible console per app in turn, you can stop after the current one, and installed status refreshes at the end. Optimaxer still does not accept agreements or hide installer windows.
- **File Explorer restarts after changes**: after a tweak or Smart Optimize run that really changed something, File Explorer restarts so interface changes show at once. The confirmation window has a checkbox for it, saved in settings and on by default; open File Explorer windows close and reopen.

## Limits
- Per-theme layouts apply to the Overview only.
- Gauges show utilisation, not temperature: Optimaxer has no temperature sensor access.
- The multi-install flow has been built and unit-checked but not run against a real batch of installs.
