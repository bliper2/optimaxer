# v2.15.36

## Startup item details

Each Startup row now opens an on-demand detail panel. It shows the original launch command and resolves supported explicit executable paths, including Windows environment variables. When present, embedded CompanyName is shown as descriptive file metadata; it is not signature verification. Shortcuts, scripts, relative commands, and ambiguous launches stay unresolved.

The Details action keeps the row’s batch checkbox behavior intact. Metadata reads run in the background and do not change startup state.
