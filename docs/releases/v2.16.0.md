# v2.16.0

The Windows desktop app gets a larger Optimaxer section, a bigger theme set and a split-up code base. The PowerShell and Linux editions are unchanged apart from the aligned version number.

## New in the desktop app
- **Black Box**: an opt-in, bounded flight recorder for CPU, memory, disk, network and GPU readings, with a timeline, sustained-saturation findings, bookmarks, a System-log lookup, Markdown and CSV export, and one-click deletion. It is off until you turn it on, records no process, window or file names, and runs only while the app is open.
- **Bottleneck Detective**: a guided 30-second measurement, or an analysis of the last hour of Black Box readings. Each finding is marked Observed or Hypothesis, carries its numbers and offers a next step. Temperature, network quality and disk saturation are listed as not assessed. There is no score.
- **Startup X-Ray**: Windows' own boot history (administrator only), a trend only when it exceeds normal variation, items Windows flagged on more than one boot, a two-boot comparison, service dependencies, a System-log lookup and boot times before and after startup changes made in Optimaxer.
- **Tweaks** has Beginner, Enthusiast and Expert detail levels. Every tweak shows whether undo is reversible, conditionally reversible or not reversible, and Expert shows exact settings, scope, derived trade-offs and the originals Optimaxer saved. No speed effect is claimed for any tweak.
- **Overview** shows a pending-restart notice from Windows' own markers, a live-activity card (GPU, GPU memory, disk, network, with unavailable readings marked) and can hide sections.
- **Seven new palettes**: Obsidian, Spectra, Ember, Tokyo Night, Rose Quartz, Aurora and Retro Terminal, 23 in total, each contrast-tested.

## Under the hood
- `app.rs` and `opti_ui.rs` are split into per-page modules; behaviour is unchanged.

## Limits
- Startup X-Ray needs administrator rights, and its parsing has been tested against sample events, not yet against a wide range of real machines.
- Black Box and the Detective read Windows counters; they diagnose nothing on their own.
