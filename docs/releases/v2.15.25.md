# v2.15.25

Network DNS benchmarks now measure real UDP A-record responses instead of TCP connection setup to port 53.

- Send five bounded `example.com` A-record queries to each provider's first IPv4 resolver.
- Show average response time, mean absolute change between successful probes, and valid-answer count.
- Validate the DNS response transaction, status and A records; show missing answers instead of inventing timings.
- Disclose that DNS probe failures are not IP packet-loss measurements and do not predict game-server latency.
- Keep the benchmark read-only and off the UI thread.

Verification: Rust test suite passes 283 tests with 6 ignored; Clippy passes with warnings denied; optimized Windows desktop build succeeds. PowerShell tests pass 54 tests; Linux tests pass 94. Live public resolver behavior still needs manual verification on Windows networks that allow UDP/53.
