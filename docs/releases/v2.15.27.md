# v2.15.27

The Rust desktop Cleaner now saves exact-path exclusions and applies them to path-based size scans, previews and cleanup. Windows.old and event-log cleanup are skipped when an exclusion overlaps their target because those system-managed operations cannot preserve an individual path safely. Recycle Bin and DISM component-store operations expose no path-level control, and the Cleaner explains that limitation.

Verification: Rust passes 298 tests with 7 ignored; Clippy, formatting and the optimized build pass. Windows PowerShell passes 60 tests and Linux passes 100. The Cleaner page was rendered at 1180 × 760. Interactive Add/Remove persistence and real cleanup on Windows remain manual checks.
