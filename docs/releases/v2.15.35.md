# v2.15.35

## Startup boot duration

The Windows Startup page now shows the latest Windows Diagnostics-Performance Event 100 boot duration and event time when available. The read runs in the existing background worker and does not change startup state.

Optimaxer does not infer per-app startup impact from launch commands. Windows must measure the app's startup CPU and disk activity before that impact can be reported responsibly.
