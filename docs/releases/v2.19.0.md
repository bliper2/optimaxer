# v2.19.0

A reworked website, new legal and security pages, a sturdier File Explorer restart and a few fixes. The PowerShell and Linux editions are unchanged apart from the aligned version number.

## Desktop app
- **File Explorer restart rebuilt**: the app checks that Explorer is running, closes it, and waits up to 10 seconds for Windows to bring it back. It starts Explorer by hand only if Windows does not, because a hand start from an elevated Optimaxer would run Explorer as administrator. If Explorer stays down, the log says how to start it.
- **New tool**: "Restart File Explorer" on the Tools page.
- **Rebuild icon cache** no longer starts a second Explorer.
- **Fixes**:
  - The "Restart File Explorer afterwards" checkbox was hidden for undo and for "apply without a restore point". It now shows for every tweak apply or undo.
  - "Undo all" now restarts Explorer when it undid something and the setting is on.
  - The Startup page said "No recent Windows boot record" when you were not an administrator. It now says only administrators can read the boot log.
  - Beginner view listed tweaks before the hardware check finished. It now waits for the check.

## Website and documents
- New landing page with features, safety steps, themes, editions and short answers, plus a FAQ and a security page.
- Privacy policy and terms rewritten for the diagnostics pages, the PresentMon download and the latency measurement, with every file and network request listed.
- `SECURITY.md`, `CONTRIBUTING.md`, issue templates and a pull request template.

## Limits
- The Explorer restart was tested with a fake system and has not been run through a real tweak on every Windows build.
- The legal pages describe what the software does. They are not legal advice.
