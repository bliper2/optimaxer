# v2.15.23

Rust desktop adds a WinGet software manager using the existing curated PowerShell package catalog.

- Search packages by name, ID, category or domain.
- Filter catalog by category and WinGet-recognized installed packages.
- Install, upgrade or uninstall one exact package ID, or request WinGet to upgrade all eligible packages.
- Review the exact command in a confirmation before it opens a visible WinGet console.
- Keep source agreements and installer prompts interactive. Optimaxer does not accept agreements or elevate automatically.
- Show exported package version when WinGet reports one, with an explicit warning that export does not match every installed app.

The Orion Store remains a download catalog. It does not install downloaded files.

Verification: Rust tests pass (274 passed, 6 ignored), Clippy passes with warnings denied, and the release build succeeds. The screenshot walk captures the WinGet page at `docs/screenshots/desktop-winget.png`. Real package install, upgrade, uninstall and inventory matching require manual Windows checks.
