# v2.15.26

WinGet catalog rows show publisher icons loaded on demand from curated icon packs and site favicons. Missing or blocked images keep the app's initial as a readable fallback. Screenshot mode loads icons by default and waits for remote images before capture.

DNS changes now save the original Windows IPv4, IPv6 and supported DNS-over-HTTPS settings before mutation. Restore validates and preflights saved records, avoids overwriting external DNS changes, verifies restoration, and retains backups after failures. Linux DNS set and restore flows require confirmation in the graphical interface, text menu and CLI; `--yes` explicitly skips the prompt.

The Rust desktop UI now shares a restrained component and theme system across Store and Optimaxer pages, with responsive layouts, palette and shape choices, reduced-motion support, and improved small-window behavior. Newer pages expose read-only diagnostics, local system snapshots and process data, while system-changing controls keep confirmation, backup and restoration paths.

Verification: Rust tests pass 293 tests with 7 ignored; Clippy passes with warnings denied; the optimized Windows desktop build succeeds. PowerShell tests pass 60 tests; Linux tests pass 100. Real DNS apply/restore on disposable Windows and Arch/Fedora NetworkManager integration remain manual checks.
