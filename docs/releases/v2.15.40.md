# v2.15.40

Smart Optimize now has a dedicated, read-only review page. It shows the detected hardware profile, current automatic recommendations, hardware-specific rules, and reasons other tweaks were excluded.

Review selects the plan in Tweaks. Exact changes remain behind the existing preview and confirmation flow, with saved-original backups and post-change verification. The page does not apply settings or claim performance gains.

Linux Python and Windows PowerShell versions are aligned at 2.15.40; this release adds no new system-changing behavior to those editions.
