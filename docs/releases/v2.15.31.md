# v2.15.31

The command palette now lists up to eight newest records from saved tweak and system-operation history. Each entry shows its action, timestamp and system-operation status where available. Selecting a record opens Activity filtered to that timestamp. Fuzzy search matches recent action titles and timestamps. Empty history keeps the existing command list unchanged.

Verification: Rust tests cover newest-first ordering, result limits, singular and plural tweak labels, title and timestamp search, and palette ordering. Release gates and Windows UI verification are recorded in `docs/verification.md`.
