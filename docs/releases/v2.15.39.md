# v2.15.39

Live system telemetry and the one-time system inventory now run on a dedicated worker thread, keeping registry, PDH, network and system-counter reads off the UI thread. Sampling pauses outside Overview and Performance, and chart history resets when sampling resumes.

Settings now offers 1, 2 or 5 second sample intervals and 30, 60 or 120 second chart windows. Preferences are persisted and invalid values fall back to the default. Chart histories stay bounded to 121 samples.

The Windows release build was run through the live app. Performance showed real CPU, memory, adapter, disk and GPU readings; Settings exposed all sample interval and chart history choices. Rust passes 320 tests with 9 ignored, PowerShell passes 60, and Linux passes 100; formatting, Clippy and the optimized build pass. No sample setting or system tweak was changed during the check.
