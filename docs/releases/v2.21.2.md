# Optimaxer v2.21.2

Free RAM now reports Windows' available physical memory before and after cleanup, along with memory load. The summary distinguishes failed cleanup steps and unavailable memory readings from a successful run. The process-list buffer grows when needed, and the PowerShell edition skips trimming its own working set.

The Windows editions explain that Windows automatically reuses cached RAM and warn that forcing a purge can slow the next app or file load. PowerShell asks before running the purge.

The Windows desktop, PowerShell, and Linux editions carry the aligned 2.21.2 version.
