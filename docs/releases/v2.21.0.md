# Optimaxer v2.21.0

## WinGet Store

Select several apps in the desktop Store and choose **Install selected** or **Upgrade selected**. Review the commands once. WinGet runs them in order in a single interactive terminal, including selections that mix Microsoft Store and WinGet packages. Each installer can still display its own setup or elevation prompt.

The Store shows the current package, lets you stop after it finishes, and keeps the batch summary visible after refreshing installed status. Closing the batch terminal stops the queue. Background inventory checks run without a visible terminal.

## Windows tweaks

- WinUtil's full multiplane overlay workaround is now an advanced, opt-in choice alongside the existing compatibility setting. It changes DWM and graphics driver policy and requires a restart. Use it for persistent display flicker.
- Classic Outlook users can hide the **Try the new Outlook** switch independently of their migration preference.
- Windows 11 users can choose up to 3, 5 or 20 recent tabs in Alt+Tab. These choices share a selection group with the windows-only layout.
- The retired drag-to-share tray setting stays available for undo on previously configured machines.

Both Windows editions include the five new choices. PowerShell has 221 active tweaks and nine retired entries. The desktop app supports 218 of the 230 catalog entries.

## PowerShell debloat

The catalog uses exact package IDs and display names for 44 optional OEM apps across seven manufacturers. This narrows publisher-wide matches and helps distinguish utilities such as Samsung Notes, HP Power Manager and ASUS GlideX. The obsolete Eclipse Manager entry has been removed.

After removal, Optimaxer checks installed packages and packages provisioned for new users once for the entire selection. It reports a verification error if Windows cannot supply either inventory.

The catalog changes adapt the latest stable releases of [Chris Titus Tech WinUtil 26.11.13](https://github.com/ChrisTitusTech/winutil/releases/tag/26.11.13) and [Raphire Win11Debloat 2026.10.30](https://github.com/Raphire/Win11Debloat/releases/tag/2026.10.30).
