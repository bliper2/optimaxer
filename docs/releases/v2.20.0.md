# v2.20.0

PowerShell catalog and undo fixes brought forward from a local v2.15.40 tree, plus the same intent in the Rust desktop app. The Linux edition is unchanged apart from the aligned version number.

## Fixes
- Disabling hibernation snapshots the previous state. Undo turns hibernation back on only if it was on. A missing `HibernateEnabled` value is treated as enabled, which is the Windows default.
- Disabling Reserved Storage snapshots the DISM state and restores that state. Undo does nothing when it was already disabled, and it refuses to guess when the saved state is missing.
- The classic boot menu restores the previous `bootmenupolicy`. The PowerShell edition treats a missing policy as `standard`. The desktop app deletes the value when the saved policy was unset, and refuses to invent `standard` when the saved record has no policy.
- Hiding the Settings home page merges `hide:home` into an existing `hide:` list (for example AI components) and restores the exact previous value. A `showonly:` policy is left alone.

## Catalog
- Eight tweaks from current Win11Debloat / WinUtil: Explorer Home and OneDrive start folders, the full taskbar search box, secondary-taskbar grouping and "show on every taskbar", Start WebView2 off, keep classic Outlook, and a complete IPv6-off option. Start WebView2 is Moderate and opt-in. IPv6-off is Advanced, opt-in, and needs a restart. Neither is in a preset or Smart Optimize.
- Extra-monitor taskbar tweaks share a conflict group, so only one layout can be ticked.
- Brave debloat sets `TorDisabled`. The extra Edge policies from the same upstream pass (`ShowRecommendationsEnabled`, feedback, Rewards, `WebWidgetAllowed`) were already on the Edge nags tweak, so they were not copied onto the second Edge tweak.
- Debloat list: alternate PC Manager id, Windows 365, Surface Hub, and Acer, ASUS, Samsung, MSI, and Lenovo Smart Appearance families (optional). Get Help and Bing Search are optional rather than recommended. Xbox TCUI is Caution because Xbox sign-in needs it.
- WinGet catalog: ImHex, OpenCode, Sysinternals PsTools, and WhatsApp and ChatGPT Desktop from the Microsoft Store source. Install, upgrade, and uninstall use `--source msstore` for `msstore:` ids.

The PowerShell catalog is 217 active tweaks plus 8 retired ones, 271 WinGet apps, and 137 Appx entries. The desktop app ports 213 of the 225 tweak entries. Disabling IPv6 stays PowerShell-only because it needs adapter-binding cmdlets. Appx removal stays PowerShell-only.

## Desktop app
- The Windows executable embeds `assets/optimaxer.ico` and version information, and the process sets the Application User Model ID `Optimaxer.OrionStore` so a taskbar pin groups with the running window.
- Microsoft Store package ids in the curated list match a WinGet export's bare Store id.

## Limits
- Hibernation, Reserved Storage, the boot menu, IPv6 unbinding, WinGet, and Appx removal were not applied on a live Windows PC in this port.
- A taskbar pin created before this build can keep a cached generic icon until it is unpinned and pinned again.

## Verification
- Desktop formatting is clean. Clippy with warnings denied passes for the Windows GNU target. The Windows test binary was executed under Wine: 377 passed, 11 ignored, and 2 failed in tests this release does not change (a long Windows path download, and live process/uptime readings).
- The debug Windows executable contains 7 icon images, one icon group, and version information for 2.20.0.
- PowerShell catalog checks passed under PowerShell 7.7. Engine tests that need the Windows registry or Windows tools did not.
