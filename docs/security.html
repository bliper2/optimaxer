Security

Last updated 4 November 2026

Optimaxer changes sensitive Windows settings, so it is built to show you each change first, keep a way back, and check what it downloads.

How downloads and updates are checked

  • Release files are published on GitHub Releases with a SHA256SUMS.txt file and the SHA-256 digest GitHub shows for each asset. Compare it with your download before you run it. In PowerShell: Get-FileHash .\file.zip -Algorithm SHA256.
  • The in-app updater downloads a release only after you press the update button. It checks the file against the digest GitHub publishes and refuses a release that has none. It keeps a backup of the files it replaces.
  • The PowerShell installer and updater check the download against the published SHA-256, and the updater rejects archives with paths that escape the install folder.
  • The PresentMon benchmark tool is downloaded from its GitHub release and checked against the published SHA-256.
  • The desktop exe is not code-signed. Windows SmartScreen may warn on first run. You can build it yourself with cargo build --release in the desktop folder.

Privileges

  • Reading works without administrator rights. Changes need them. The desktop app asks only when you press Restart as administrator, and Windows shows its own approval prompt.
  • Services Windows depends on are on a protected list, and Optimaxer does not offer to disable them.
  • Risky tweaks are never part of an automatic plan, and no built-in tweak turns off Microsoft Defender.
  • Undo uses saved records and refuses to act if a record is damaged or the setting was changed elsewhere, so it does not guess.

What stays on your PC

Settings, undo records, history and diagnostic readings are local files. The privacy policy lists the files and every network request.

Report a vulnerability

Please do not post exploit details in a public issue.

  • Use the Report a vulnerability button on the Security tab if it appears.
  • If it does not, open an issue titled "Security contact request" with no technical detail, and the maintainer will arrange a private channel.

Include the edition and version, the steps to reproduce, and what an attacker could do. You will get a reply on the issue, and fixes ship as a new release with a note in the release text.

Supported versions

Only the latest release receives fixes.
