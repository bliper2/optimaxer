Frequently asked questions

Last updated 4 November 2026

Using it

Is Optimaxer safe to run?

It is open source, previews every change and saves the original value for undo. It still changes system settings, so create a restore point first and read the description of any Moderate or Advanced tweak. The terms cover the details.

Does it need administrator rights?

Reading works without them. Applying tweaks, changing services and cleaning system files need administrator rights. The desktop app shows a banner with a Restart as administrator button, and Windows asks you to approve it.

How do I undo a tweak?

Select it on the Tweaks page and choose Undo selected, or use Undo all. Each tweak is labeled reversible, conditionally reversible or not reversible. Deleted cache files and cleared event logs cannot come back.

Will it make my games faster?

Some tweaks help some PCs, and Optimaxer makes no promise. Record a benchmark before and after with PresentMon and compare average FPS, the 1% and 0.1% lows and stutters. Small differences fall inside normal run-to-run variation.

Does it turn off Microsoft Defender or Windows Update?

No built-in tweak turns off Defender. A few Moderate tweaks change Windows Update behavior, for example pausing updates for 35 days, delaying feature updates or stopping automatic driver installs. One tweak stops Windows from turning on BitLocker device encryption by itself. The preview names each of these.

Why does it restart File Explorer after a tweak?

Many interface tweaks only show after Explorer reloads. The desktop app restarts it after a run that changed something, and Windows brings it back on its own. Open File Explorer windows close. Clear the checkbox in the confirmation window to skip it, and the choice is saved.

What does Black Box record?

Processor, memory, disk, network and GPU readings at the interval you choose, and bookmarks you add. It is off by default, keeps a rolling window in a local file, and never records process names, window titles or file names. You can export a report or delete the history.

Why does Startup X-Ray ask for administrator rights?

Windows lets only administrators read its boot performance log. Optimaxer reads that log and changes nothing. Without administrator rights the page offers a restart button.

Downloads and updates

Windows SmartScreen or my antivirus warns about the exe. Why?

The desktop exe is not code-signed, and tools that edit system settings often trigger warnings. Compare the file's SHA-256 with the one on the release page, or build it yourself from the source. If a warning persists after the hashes match, report it on the issue tracker with the scanner's name and version.

How do updates work?

The desktop app checks GitHub once per launch and shows an Update button for a newer release. Nothing downloads until you press it. The app checks the zip against the SHA-256 GitHub publishes, backs up the old file and restarts. You can turn the check off in Settings.

Which Windows versions work?

Windows 10 and 11. Some tweaks need a newer build, and the app hides or skips the ones that do not fit your PC.

Is there a Linux version?

Yes, a separate Python edition for Manjaro and other Arch-based systems and for Fedora. It has been tested on a simulated system, so run it with --dry-run first. A Linux build of the Rust app is in development.

Data and removal

Does it send my data anywhere?

No. There is no account, analytics or telemetry. It contacts GitHub for updates and the catalog servers you ask it to. The privacy policy lists every request.

Where does it keep its files, and how do I uninstall it?

The desktop app uses %LOCALAPPDATA%\OrionStore, and the PowerShell edition uses %LOCALAPPDATA%\Optimaxer and %ProgramData%\Optimaxer. Undo your tweaks first if you want the old settings back, then delete the program and those folders.

Help and licensing

How do I report a bug or ask for a feature?

Open an issue on the issue tracker. Include the edition, the version and what you did. For a security problem, read the security page first.

Can I use it at work or in a business?

The licenses allow it, but your employer or device administrator decides what you may change on a managed PC. The PowerShell and Linux editions use MIT. The desktop app uses GPL-3.0, which applies when you redistribute it.
